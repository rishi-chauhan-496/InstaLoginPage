# App Screenshots Directory

Place your screen capture images in this directory with the following filenames:

- `login_screen.png` - Screenshot of the Instagram Login screen
- `forgot_password.png` - Screenshot of the Password Recovery screen
- `create_account.png` - Screenshot of the Create Account screen
- `home_screen.png` - Screenshot of the Home Feed screen with stories and posts
- `profile_screen.png` - Screenshot of the User Profile screen

---

### How to export screenshots from Android Studio Compose Previews:
1. Open [`LoginActivity.kt`](../app/src/main/java/com/example/instalogin/LoginActivity.kt) or [`HomeActivity.kt`](../app/src/main/java/com/example/instalogin/HomeActivity.kt) in Android Studio.
2. Switch to **Split** or **Design** view to view the Compose Previews.
3. Right-click on any preview -> **Copy Image** or **Save Image As...**
4. Save the file into this `screenshots/` directory with the matching filename above.
5. Push to GitHub!
